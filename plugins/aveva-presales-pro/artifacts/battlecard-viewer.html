AVEVA Battlecard Viewer

Browse the plugin's competitor battlecards interactively. Audience-signals selector toggles framing per buyer posture. Refresh button opens the competitor's official source in a new tab.
AVEVA, part of Schneider Electric · Watermark: appro-ca96e5c3-e535-40b4-a502-9e85523f608e · aveva-presales-pro v0.3.2
Battlecard data is inlined from artifacts/battlecards-snapshot.json at plugin build time (so the viewer works as a self-contained Cowork artifact with no file fetch). Each card carries a last_validated field; values older than 90 days surface as "stale" and trigger a content-health audit recommendation.
